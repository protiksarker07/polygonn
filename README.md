# polygonn

Website for **polygonn** – practical GIS courses, projects, resources and an interactive lab.

Pure static site (HTML, CSS and JavaScript in one file). No build step.

## Structure

```
index.html            the whole website
assets/logo/          logo files (SVG + transparent PNG, dark/light versions)
assets/favicons/      favicon.ico, PNG icons, apple-touch-icon
.nojekyll             tells GitHub Pages to serve files as-is
```

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Repository **Settings → Pages**
2. Source: **Deploy from a branch**, branch **main**, folder **/ (root)**
3. Save. The site goes live at `https://<your-username>.github.io/<repo-name>/`
